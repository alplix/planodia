| [PLA-001] | high | boinc-lifecycle | boinc_time_to_checkpoint() is called twice per checkpoint, so a critical section stays open and suspend, quit and abort stop working | In main() call boinc_time_to_checkpoint() once per light curve, keep it in a bool, pair each 1 with one boinc_checkpoint_completed() (main:194-196) [PAT-001] |
| [PLA-002] | med | device-selection | The OpenCL device comes only from --device; init_data's gpu_opencl_dev_index is never read | In main(), read APP_INIT_DATA and use gpu_opencl_dev_index when >= 0, --device only as fallback; fix together with PLA-003 [PAT-011] |
| [PLA-003] | med | device-selection | OpenCL devices are counted as CL_DEVICE_TYPE_GPU but fetched as CL_DEVICE_TYPE_ALL, and the ALL fallback can pick a CPU device | In gpu_init(), use CL_DEVICE_TYPE_GPU for both the count and the list, drop the CL_DEVICE_TYPE_ALL fallback, log vendor, type and name [PAT-012] |
| [PLA-020] | med | data-pipeline | ingest.py writes a shard even when downloads failed, so those light curves are never fetched again; a cut target-list download is reused as complete | In ingest.py, tell a 404 from a failed fetch, do not write a shard after a transient failure, download the target list to a temp name [PAT-023] |
| [PLA-004] | low | checkpoint | trim_output() rewrites out in place, and the checkpoint and trim writes are not checked | Add one helper (temp file, checked writes and close, boinc_rename) for trim_output() and write_checkpoint(); report only on success [PAT-003] |
| [PLA-005] | low | boinc-lifecycle | Progress is not reported after a resume until the next light curve is finished | In main(), call boinc_fraction_done((double)done / total) right after out is opened on resume (after main:163) [PAT-007] |
| [PLA-008] | low | build | The Android build takes the OpenCL headers from /mnt/c/temp, and every build script uses fixed machine paths | In tools/build_android.sh replace -idirafter /mnt/c/temp and the /root paths by variables (CL_INC, NDK, BOINC_SRC) with today's values as defaults [PAT-021] |
| [PLA-012] | low | io | Write errors on out are not checked before boinc_finish(0), so a truncated result can be reported as a success | In main(), check fprintf/fflush/fclose on out (or ferror before fclose); on failure no boinc_finish(0), exit so the resume repairs out [PAT-006] |
| [PLA-013] | low | checkpoint | A checkpoint or out that cannot be opened is treated as a fresh start, and out is truncated | In read_checkpoint() and trim_output(), treat only !boinc_file_exists() as a fresh start; other open failures -> boinc_temporary_exit(300, ...) [PAT-005] |
| [PLA-015] | low | gpu-runtime | OpenCL buffer writes, reads and kernel arguments are not checked, so a failed transfer silently reuses old data | In gpu_scan(), check every clEnqueueWriteBuffer, clSetKernelArg and clEnqueueReadBuffer, return false on error; clear host results first [PAT-027] |
| [PLA-021] | low | build | The build image, packages and BOINC library versions are not pinned or recorded, so a release cannot be rebuilt as it was | Print image digest, package versions, compiler --version and the BOINC tree's git commit into each build log; pin ubuntu:20.04 by digest [PAT-029] |
| [PLA-022] | info | gpu-runtime | The required work-group size of 64 is checked against the device limit but not against the compiled kernel's limit | In gpu_init(), query CL_KERNEL_WORK_GROUP_SIZE after clCreateKernel and refuse the device with a clear message when it is below 64 [PAT-015] |
